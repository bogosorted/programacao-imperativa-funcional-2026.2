a: Vai imprimir "Opcao B". Isso acontece porque o else sem chaves se junta ao segundo if (if (y > 10)). Como x > 10 e verdadeiro (15 > 10), o programa entra no primeiro if, testa se y > 10 (5 > 10), que da falso, e cai direto nesse else.
b: No C, a regra diz que um else sem chaves sempre se associa ao comando if mais proximo antes dele que ainda nao tenha um else.
c:
int x = 15, y = 5;
if (x > 10) {
    if (y > 10) {
        printf("Opcao A\n");
    }
} else {
    printf("Opcao B\n");
}
