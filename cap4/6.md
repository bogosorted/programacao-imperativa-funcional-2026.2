Varias mensagens sao exibidas porque foram usados comandos if separados. Como 65 e maior que 60, 18 e 12 ao mesmo tempo, todas as tres condicoes dao verdadeiro.
b: Nos comandos if independentes, todas as condicoes sao testadas uma por uma, mesmo que uma anterior ja tenha dado verdadeiro. Na cadeia else-if, assim que uma condicao e verdadeira, o bloco dela roda e todas as outras abaixo sao ignoradas.
c:
int idade = 25;
if (idade >= 60) {
    printf("Idoso\n");
} else if (idade >= 18) {
    printf("Adulto\n");
} else if (idade >= 12) {
    printf("Jovem\n");
} else {
    printf("Crianca\n");
}
