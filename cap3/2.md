a: Porque a variavel soma foi declarada dentro do for e nao existe fora dele (erro de escopo).
b: Porque a cada iteracao o int soma = 0 ia zerar a variavel, ela nunca iria acumular a soma total, so ia mostrar o quadrado da iteracao atual.
c:
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0;
    for (i = 1; i <= 9; i++) {
        soma += i * i;
    }
    printf("Soma final = %d\n", soma);
    system("PAUSE");
    return 0;
}
A visibilidade e o escopo de bloco fazem com que variaveis criadas dentro de chaves so existam la. Colocando soma fora do for, ela dura ate o fim do main.
