a: Porque a variavel soma foi declarada dentro do laco for, entao ela nao existe fora dele por causa do escopo de bloco.
b: As iteracoes de 1 a 8 comecam, mas o continue na 5 pula a soma, e o break na 8 para o laco imediatamente.
c:
#include <stdio.h>
#include <stdlib.h>

int main() {
    int i;
    int soma = 0;
    for (i = 1; i <= 10; i++) {
        if (i == 5) continue;
        if (i == 8) break;
        soma += i * i;
    }
    printf("Soma final = %d\n", soma);
    system("PAUSE");
    return 0;
}

O resultado que sera impresso: Soma final = 115
